## Installation

### 1. Copy the plugin URL

```text
https://raw.githubusercontent.com/whywouldyouneedthatfromme-ship-it/revenge-plugin/refs/heads/main
```

### 2. Open Revenge settings

1. Open Discord.
2. Open **Revenge**.
3. Go to **Settings**.
4. Open the **Plugins** section.

### 3. Add the plugin

1. Find the plugin install/import field.
2. Paste the plugin URL:

```text
https://raw.githubusercontent.com/whywouldyouneedthatfromme-ship-it/revenge-plugin/refs/heads/main
```

3. Confirm the installation.
4. Enable the plugin if it is not enabled automatically.
5. Restart Discord/Revenge if the plugin does not appear or work immediately.

## Usage

After installing and enabling the plugin:

1. Open Revenge settings.
2. Go to **Plugins**.
3. Find **Message Logger** in the plugin list.
4. Open its settings if available.
5. Configure the plugin as needed.

If the plugin has no settings menu, it should work automatically after being enabled.

---

## Troubleshooting

### The plugin does not appear

- Make sure you pasted the correct URL.
- Check that Revenge is installed and working.
- Restart Discord/Revenge.
- Make sure the plugin is enabled in **Revenge → Settings → Plugins**.

### The plugin does not work

- Check for Revenge updates.
- Disable other plugins temporarily to rule out conflicts.
- Reinstall the plugin using the same URL.
- Restart Discord completely.

### The URL does not load

- Copy the URL again and make sure there are no extra spaces.
- Check your internet connection.
- Try opening the URL in a browser to verify it is reachable.

---

## Uninstall

1. Open **Revenge → Settings → Plugins**.
2. Find **Message Logger**.
3. Disable or remove the plugin.
4. Restart Discord/Revenge.
